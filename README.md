# 《注释》— 小说创作工程

> 一部**文学向生活流科幻**单元剧短篇集。一个 2026 年的程序员穿越到 2055 年——一个模型代理制、配额供给制的停滞世界，用代码思维在制度缝隙里讨生活，给荒诞世界写注释，也给自己的人生写注释。
>
> 第一季 10–12 集，每集 3000–5000 字，第一人称。**定位路径 A**：世界观重量 / 主题深度 / 人物真实优先，允许慢热，改编是结果而非前提。

## 写作工作流

1. 开写一集前 → 读 `constitution.md` 红线 + `season1-settings-inventory.md` 确认本集启用哪几条设定
2. 起草 → 对齐 `ep01-quality-gate.md` 认证的标杆节奏与文风
3. 写完 → 过质量门禁（五维评分 + 去 AI 感四感检查）
4. 定稿 → 更新 `spec/tracking/` 四本台账（伏笔 / 时间线 / 角色 / 关系）
