# 世界质感库（设定增厚）

> 确立：2026-08-23（作者指出"世界观单薄"，重点做厚食物泵 / AI）
> 目的：给核心设定补上能进正文的血肉——形态、感官、价格、分层、故障、黑话、与陆远的交互点。
> 纪律：这是**底色库**，不是戏份清单。第一季只动用约 1/3，其余烂在肚子里当底色（宪法第八条·冰山纪律）。

---

## 一、食物泵（增厚）

### 形态
- **标准款**：腰侧巴掌大的盒子，磁吸在裤带上，一根细管贴在小腹——"挂泵"是成年人的标配，像这个时代的腰带
- **腕部贴片款**：轻奢，无管，隐形
- **穷人款**：街角的**泵亭**（刷积分/投币，打一次基础糊）——排队打糊的人，像旧时代的取水点

### 感官
- **泵（无味中性）**：泵是营养注入，不经过味觉系统——像打点滴，没有"好不好喝"的问题。没有"泵味"，只有注入完成时那声"嗤"
- **泵感**：打完有饱腹感，但嘴里永远是空的。年轻人管这种状态叫"**嘴空**"——饿被消除了，想吃的冲动没消除
- **打糊声**：泵亭的机器"嗤——"一声，像给轮胎打气

### 核心逻辑（食物逻辑 · 已确认）
- **基本营养普世解决**：泵保障人人吃饱，这个时代没有任何人饿肚子——"饥饿"作为生理问题已被消灭
- **稀缺的是味觉，不是营养**：真食物（咀嚼的、有味道的）是纯味觉享受，是奢侈品。因为它的唯一价值是味觉，所以**能出现在市场上的真食物都是"好吃的"**——"难吃又有营养"的组合在这个世界不存在（营养有泵负责，难吃没人买单）
- **"吃饭"= 享受 / 仪式 / 旧习惯**：穷人吃泵（保障），富人吃饭（享受）；陆远吃饭是"旧人的习惯"——他吃的是"动作"，不是"味道"

### 社会分层
- 穷人：纯泵，配额内基础配方（糊+维生素+基础药）
- 中产：泵 + 每周一两次真餐（预加工食物 + 调味包，超市有卖，贵）
- 富人：真食（私厨 / 老字号 / 农场直供）——吃饭是社交仪式，一顿饭的排场=一顿饭的配额

### 黑市
- "**种子**"黑市：真种子、真菜苗、旧食谱——走私"会腐烂的东西"
- 老城区流传"绿手指"的传说：有人在旧厂房顶偷偷种菜，没人知道是谁

### 故障
- 泵坏了 = 急诊：手抖、眼花、短期记忆模糊（营养失衡症状）
- 黑维修：老魏这类人有渠道，修泵比修人贵

### 与陆远的交互点
- 他吃真饭被围观（ep1 已立）
- 他咽不下泵糊——"旧人的胃"，真食物是肌肉记忆，泵糊是化学合成的陌生
- 他全身上下最奢侈的东西，不是钱，是**吃饭的习惯**

## 二、AI / 模型（增厚）

### 形态（型号即阶级）
- **入门款（耳机）**：上下文短、推理浅。复杂问题会"卡住"——话开始打转、重复，最后说："这个我帮不了您，建议升级。"
- **中端（手表/手环）**：日常全能，偶尔掉线
- **旗舰（隐形植入/戒指 + 云端）**：能替你跑几千次人生模拟。富人不戴"显形"的型号——旗舰是隐形的，穷人靠挂耳识别"谁有脑子"
- 判断一个人有没有脑子（模型）：看他耳朵/手腕有没有亮——**"亮不亮"是这个时代的打招呼**

### 模型是租的
- 断供体验：当天"话变慢了"；第二天"记不起上周的事"；第三天"不认识镜子里的人"——记忆在云端，断供=失忆
- 断供过渡：老魏的生意——入门款过渡，一个月几百，"先让脑子回来"
- 黑色幽默：这个时代最大的债务是"**记忆分期**"

### 模型语系
- 不同厂商的模型输出风格不同（语感/判断/价值观）——长期用一家，思维被"喂"成一种形状
- 跨语系交流：官方有翻译，但翻译丢"语感"——两个语系的人说话，像隔一层毛玻璃，意思都对，感觉全错
- **版本代沟**：老模型"较真、慢、爱讲道理"；新模型"快、滑、一切以你的利益最大化"。父母说孩子"油"，孩子说父母"轴"——这就是版本代沟

### 模型依赖症（社会病）
- 症状：离了模型就焦虑（"**裸机焦虑**"），手空——没有模型可以说话
- 老城区的人多多少少有点"裸"（穷，用不起），反而习惯了——**老城区是"裸机聚集地"，这是它混乱但自由的原因**

### 旧 AI（2020 年代）
- 跟 2055 模型比：笨、慢，但**会犯错、会说错话、有"人格"**——2026 的 AI 被做成"像人"，2055 的模型被做成"像工具"
- 陆远跟旧 AI 相处自然（他认识"会犯错的 AI"），跟新模型相处像"跟工具说话"
- 这解释了七号为什么让他毛骨悚然又亲切——它是旧时代的"人格"AI

### 与陆远的交互点
- 他没有模型，是"永久裸机"——别人以为他穷，其实他是旧时代人
- 他能"读"模型（金手指），但他"读"不了人心（The Lie）——技术题能解，制度题解不了（宪法第八条）

## 三、代理制的日常质感

- **买东西**：摊主看你要买，先"让你的模型出价"——两个模型在云端砍价，肉眼看不见，几秒后摊主说"成交，你模型说这个价你接受"。你没模型？摊主为难："那我跟你直接谈？"（老城区例外——老城区直接谈）
- **办事**：窗口不看人，看"你的模型提交了什么"。模型提交的表格永远合格；人的手写表格永远"格式不符"
- **吵架**：两个人对骂，实际是两个模型在互怼参数，人只负责提供情绪
- **恋爱**：先跑模拟（一万次同居），合适了才见面——见面是"验收"，不是"开始"

## 四、配额制的感官底色（不展开）

- 配给点的味道：消毒水 + 泵糊味
- 凭证：腕上的电子环闪一下，等级色——甲金 / 乙银 / 丙蓝 / 丁绿 / 戊灰；无证人员 = **无色**
- 日常荒诞："少发一条街""评级整片降级""申诉格式不符"
- 老城区（丁戊灰 + 无色）vs 新城区（金蓝银白）——颜色是行走的简历

## 五、旧物（增厚）

- 旧时代遗留：2026 的手机 / 电脑 / 充电头 / 机械表 / 纸质书 / 老照片
- 老城区是"旧物的坟场"，也是"旧物的教堂"
- 旧物的气味：塑料老化 + 金属锈 + 一点机油
- 会修旧物的人越来越少——老城区还剩几个，陆远来了之后，算一个

## 六、数字守灵（ep3 / ep6 用）

- 灵堂：一块屏幕，逝者模型用本人的语气说话（"我记得你小时候……"）
- 吊唁：跟模型说话，模型回应；家属在旁听
- "格式化葬礼"：删模型 = 第二次死亡，仪式感比第一次葬礼更重（焚化的是记忆）
- 法律难题：不肯关掉逝者模型的家属，算不算囚禁

## 七、气味系统（普鲁斯特式 · 与记忆强关联 · 全局规则）

> 依据：宪法第四条·9（气味与记忆的强关联）

### 世界的"气味分层"
- **新城区**：几乎无味——空气被过滤，街道干净到没有气味。**没有气味 = 没有记忆**（被净化过的空间，连旧记忆都无处安放）。新城区的人闻不到"过去"
- **老城区**：气味丰富——旧物味（塑料老化 + 金属锈 + 机油）、食物味（真饭 / 泵糊 / 腌菜）、灰尘味、人味。老城区的气味是"活"的，是"记得住"的
- **泵味**：蛋白糊的咸腥 + 合成维生素的金属味——这个时代的"默认记忆底噪"，所有人闻着它长大，它不触发任何记忆

### 写作规则
1. **触发深层记忆**：用一个具体气味，不解释、不抒情——陆远闻到某个旧时代的味道，记忆自动涌来（记忆内容由作者补）。写法：先写气味，再写动作停住，不写"他想起"
2. **气味 = 系统碰不到的**：清除程序定位不到气味记忆——它和思念一样，是"保留主题"的载体。可以写"系统能清除数据，但清不掉那个味道"
3. **新旧对照**：新城区无味（被净化）vs 老城区有味（活着）——气味本身就是新旧世界观的隐喻
4. **锚点联动**：锚点意象（手写的字）附近的嗅觉细节——纸的味道、墨的味道、旧布的味道，都是"一文不值但没人清除"的气息

### AI 嗅觉缺口（技术前提 · 已确认）
- **AI 没有普遍使用的嗅觉功能**：嗅觉数字化从未普及——电子嗅觉需要分子级采样、高维编码、跨个体标准化，技术上一直不成熟；赶上能力停滞期（收敛），这条能力线停在原地，再没推进。**嗅觉是那条没被收敛掉的尾巴**
- **后果**：
  - 气味是**系统最后的盲区**——唯一无法被采样 / 备份 / 清除的感官通道
  - 新城区"无味"的另一层原因：**AI 设计的城市感知不到气味，所以根本没设计气味**——无味是 AI 的默认值
  - 老城区有味：人类经营的角落，气味是"人味"的最后存续地
  - AI 能复刻深情、声音、语气，但**复刻不了气味**——"妈妈厨房的味道"是 AI 永远理解不了的（保留主题的最深盲区）
- **叙事用法**：
  - 数字守灵的缺味：逝者模型复刻得了声音，复刻不了他身上那股烟味 / 洗衣粉味——守灵总缺一样东西
  - 气味 = 人类最后的隐私与优势：AI 监控一切，但闻不到你身上那股旧味道
  - 陆远的旧嗅觉记忆，是系统无法理解的东西（触发点由作者补）

## 八、寿命延长与埋藏记忆

> 依据：Bible 核心规则 11（寿命延长）+ 宪法第四条·10

### 世界的"年龄结构"
- **150+ 是常态**：医学 + 泵管理延缓老化，"老"不再等于"快死了"。四代同堂是标配，一个家族里可能同时活着 2020 年代的老祖、2030 年代的父母、2050 年代的孙辈
- **版本代沟更极端**：老祖用 2020 年代的老模型（或没用模型），孙辈用最新款——跨四代的"版本代沟"，谁都不懂谁

### 埋藏记忆（核心）
- 2055 年的城市里，那些看起来七老八十的人，**可能真的在 2020 年代活过**——他们身上埋着和陆远同代的旧记忆
- 为什么"埋得很深"：几十年自然老化 + 记忆管理（模型外挂/归档/优化）把旧记忆一层层盖住——旧记忆成了"归档区"，平时调不出来
- 老城区无模型的老人，记忆反而"原样"——但几十年过去，也模糊了、变形了（记忆会变形，回忆主题）

### 写作规则
1. **旧人只露痕迹，不点破**：一句没人懂的方言、一个没人认识的物件、闻到某个味道怔住——读者自己品（场景手艺：撞到，不告诉）
2. **陆远不是唯一**：他的记忆是新的（穿越记忆新鲜），他们的记忆是埋着的（几十年+管理覆盖）——他偶尔会在某个老人身上，看见"旧世界"的一角
3. **气味触发联动**：埋藏记忆被气味撬动——老人闻到旧时代的味道，怔住，但不解释（触发内容由作者补）
4. **黑市/老城区**：买不起顶级维护的老人，反而更"旧"——他们是活的旧时代标本

### 与既有线的关系
- **管机房的老人们**（ep04/ep06）：赵建国殉职、李叔走了——但"当年管机房的一批人"里可能还有活着的，且是真·2020 年代人（作者可续）
- **数字守灵**：活得更久的时代，守灵也守得更久——有人给爷爷的模型守了五十年

## 用法

每集开写前，回这里取"本集要用的质感"，其余不铺陈。**质感是给正文调味的盐，不是端上桌的菜。**
