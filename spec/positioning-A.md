# 定位路径 A — 执行准则

> 确立：2026-08-22（作者确认「按 A 走」）
> 地位：**执行层准则**，不修改世界地基。冲突时优先级：`constitution.md` > `settings/world-foundation.md` > 本文件。
> 作用：把"文学向优先、允许慢热、改编是结果非前提"这个定位，翻译成写分集和正文时可执行的动作。

---

## 决策

**路径 A：一部有改编潜质的严肃生活流科幻。**
先把作品写到极致，改编价值自然浮现（参照《黑镜》），**而不是**先为抖音短剧的节奏逻辑（3 秒钩子 / 爽感前置 / 强反转密度）设计故事。

作品的价值锚点，按优先级：
1. 世界观重量（停滞机制 + 保留主题的思辨深度）
2. 主题真实（"明知有更优解，仍停在次优解里"）
3. 人物真实（陆远不是爽文主角）
4. 画面感 / 可改编性——**排在最后，是前三者的副产品，不反向驱动**

---

## 四条执行准则

### 准则 1 · 配额制降格为背景压力
- 世界地基里的配额制设定**全部保留**，但在分集与正文里，它只承担"生存压力 / 制度荒诞的日常底色"，**不当主戏**。
- 主场永远是 **代理制 + 保留主题（思念 / 爱情 / 亲情 / 回忆）**——这才是本作区别于一切同类的核心资产。
- 判断标准：一集的情感高点若来自"配额 / 等级 / 均衡局"，多半跑偏了；若来自"技术做得到、人却选择笨拙"，就对了。

### 准则 2 · 金手指克制（守住去英雄化）
- 陆远"能读懂旧设备 / 能读穿别人的模型"——**能读懂 ≠ 无往不利**。
- 硬性边界：**技术题他能解；等级、人心、已经发生的事，他解不了。** 这正是他的 The Lie（"逻辑足够严谨就能解决任何问题"）要被反复打碎的地方。
- 每集若出现"主角靠金手指碾压全场、毫无代价地赢"，判负重写。赢要付代价，且代价常常是"赢了技术、输了人"。

### 准则 3 · 早期情感锚点（慢热 ≠ 冷启动）
- A 允许慢热，也允许把**最深主线（前女友 / 思念 / 穿越之谜）继续藏**——这部分内容由作者补充，本准则不预设、不触碰。
- 但即便文学向，读者也需要一个**早期情感落点**才愿意留下来。
- 动作：在前 3-4 集内，用一条**非主线**的情感单元给一次真正的情绪重击（候选：亲情 / 版本代沟，或数字守灵线——两者均为 bible 内可动内容）。让前段不至于纯靠"世界观奇观 + 吐槽"驱动。
- 这不改变第 9 集思念线、第 12 集主线推前台的既定节奏——只是在它们之前先建立情感信任。

### 准则 4 · 设定减负（第一季启用清单）
- 世界观是长篇的设定体量，媒介是短篇集。**克制是纪律：第一季能真正用上的设定约 1/3，其余烂在肚子里当底色。**
- 每集开写前，明确"本集启用哪几条设定"，其余不解释、不铺陈（冰山原则，宪法第七条）。

## 对"暗夜灵魂"（第 10-11 集）的专项提醒

"拥有一切却毫无痛感 / 没有一件事非他不可"是**存在主义式绝望**，不是戏剧性绝望。文学向不代表可以只写抽象的空。
- **必须给这个内在空洞一个具体、可视化的外部承载事件**，否则易被读成"男主凡尔赛"。
- 承载事件由作者 / 后续分集细化时定；本准则只标记这是第 10-11 集的头号风险点。

## 不做什么（A 的红线）
- 不为留存率把主线提前、把谜底浅白化。
- 不加"强钩子回目"式的硬反转去凑短剧节奏。
- 不把陆远写成开挂爽文主角。
- 不因"这段不够抓人"就往里塞奇观或狗血——先问"是不是主题不够真"。
