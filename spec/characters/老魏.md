# 老魏 · 角色形象档案（v1.0）

> 用途：角色形象生成一致性依据。
> 定位：合唱团"共谋又清醒的中间态"——靠 AI 吃饭（算法调解师）却看穿它；想上岸却困在系统里；**陆远"妥协了会变成谁"的预演**。
> 依据来源：ep02（名片）/ ep09（上门谈生意）/ ep11-12（收尾）正文 + novel-bible.md。

---

## 一、基本信息

| 项 | 值 |
|----|----|
| 姓名 | 老魏 |
| 年龄 | 五十上下（"替人走了半辈子流程"） |
| 身份 | 算法调解师（前均衡局文书，被排挤下海）——帮人钻流程空子的灰色中间人 |
| 记忆点 | 公文包不离手；"正规流程走不通——可越是流程走不通的事，越有门儿"；"等我上岸就退休"（钱越攒越厚，上岸越推越远） |

## 二、身体数据（生图硬参数）

| 项 | 值 | 说明 |
|----|----|------|
| **身高** | 170 cm | 不高不矮 |
| **体重** | 72 kg | 微胖——久坐办公、应酬的底子；不是壮，是"坐出来的" |
| **体型** | 圆润、肚子微凸、肩圆 | 前文书/现调解师的体面与松懈并存 |
| **手** | 白净、软 | 不干活的手——他是"动嘴皮子"的，不是"动手"的（与陆远形成对照） |
| **体态习惯** | 坐马扎/坐办公室 | 公文包搁在膝盖上（ep09"像个来验收的领导"）；说话时习惯压低声音 |

## 三、面部与发型

| 项 | 值 |
|----|----|
| **脸型** | 圆脸、和气——第一眼看是个好说话的中年人 |
| **眼睛** | 精明：看人时打量得很快，笑着也在算账；但偶尔露一次真（ep09 说钉子户时） |
| **发型** | 黑发中分/偏分，打理过但有点油——中年男人的体面 |
| **五官** | 笑起来眼角有褶子；下巴圆；穿得比实际身份体面半级（调解师的职业需要） |
| **气质** | **滑头但讲信用**：说话圆滑、见人三分笑，但答应的事会办到；心里清楚这个时代是什么样，嘴上不点破 |

## 四、穿着

> 原则：体面半级的"门面"——他的营生靠"看起来靠谱"。

| 单品 | 描述 |
|------|------|
| **公文包** ⭐ | 旧但保养得好——他的招牌（ep02 名片、ep09 上门都带着）；里面是材料、合同、名片 |
| 上衣 | 旧西装外套（不太合身、料子一般但干净）——"像个来验收的领导" |
| 内搭 | 白衬衫/灰衬衫，领口扣子常不扣（放松） |
| 下装/鞋 | 西裤 + 旧皮鞋，皮鞋擦过（亮但旧） |

## 五、标志性元素

1. **公文包**——身份道具：他的一切"门路"都在包里
2. **压低声音**——谈生意、谈灰色活时声音放低（ep09"压低声音"）
3. **马扎**——上门不坐人家的椅子，坐自己带的马扎（疏离的客套）
4. **"有门儿"**——口头禅：越是流程走不通的事，越有门儿
5. **表情基准**——笑面、打量、算账；说"活明白了的人不吃香"时，有一瞬真

## 六、与世界观的咬合

- **前均衡局文书**——他见过系统内部，所以看穿它；但他靠钻它的空子吃饭（共谋）
- **"上岸"永远推迟**——他的 Lie："只要足够懂流程，就能全身而退"——而 ep09 他自己承认"钱越攒越厚，上岸越推越远"
- **与陆远的镜像**：陆远"不懂系统但选择不碰"，老魏"懂系统但选择钻"——他是陆远妥协后的样子，也是陆远"不妥协"的提醒
