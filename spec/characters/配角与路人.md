# 配角与路人 · 角色速查档案（v1.0）

> 用途：全剧出现过的所有配角/路人的一致性速查——写续集、做分镜、生图时按此取特征。
> 说明：分三档——**熟脸配角**（多集/关键戏，特征详）、**单集角色**（有完整戏份）、**路人**（一句带过的交流）。生图提示词仅给熟脸配角。

---

## 一、熟脸配角

### 李叔（ep06 数字守灵）
| 项 | 值 |
|----|----|
| 身份 | 赵满秋父亲（赵建国）的老同事，当年管机房的一批人之一；后搬新城区；ep06 去世 |
| 生前形象 | 爱抽旱烟，身上总带着烟味和樟脑味；略微驼背（模型复原的姿态） |
| 模型形象 | 屏幕里坐着的"李叔"：**灰夹克、略微驼背、坐在沙发上**——"像真的"；"不会累，不会老，不会问'我女儿今天怎么没来看我'" |
| 关键词 | 灰夹克 / 驼背 / 旱烟 / 樟脑味 / 答录机式的"爸，知道了" |

### 刘婶（ep08 版本代沟）
| 项 | 值 |
|----|----|
| 身份 | 老城区本地人，五十多岁，裁缝铺（改衣服/缝裤脚），刘小满之母 |
| 形象 | **坐在缝纫机前，低着头，用老式的针脚锁边，锁得很慢，很仔细**；说话慢、土、直 |
| 关键词 | 缝纫机 / 老式针脚 / "为你好"（翻译过来是控制）/ 梯子上摔下来那句"别慌，妈接住你了" |

### 刘小满（ep08 版本代沟）
| 项 | 值 |
|----|----|
| 身份 | 刘婶之女（随母姓），新城区上班，做数据分析 |
| 形象 | **耳朵里挂着耳机（代际翻译）**，一脸疲惫；看手腕上的屏幕查翻译 |
| 关键词 | 耳机 / 代际翻译 / "准得太准了"/ 七岁从老槐树摔下来 / 给她妈买护踝（"给脚用的"） |

### 周成（ep05 你的模型报价了吗）

|----|----|

| 关键词 | 卡住 / 手抖 / 咖啡 / "我想喝它" / 走得很急像怕自己反悔 |

## 二、单集角色

### 瘦子（ep04）
常来送旧电器的；蹲在旧货铺门口；压低声音讲城西废机房的传说（"嗡——嗡——嗡——"）；"所以说是鬼嘛"嘿嘿笑。

### 卖废铁的老头（ep01）
旧货巷的回收人；压低声音警告"均衡局判过死刑的东西碰了要担责"；事后给半袋干粮和硬币（"修好旧东西的人能拿旧东西换钱"）；"这事儿，别往新城区说"——**老城区隐秘规矩的第一见证人**。

### 老太太（ep04 第 37 个微波炉）
微波炉主人，坏了三个月舍不得扔——"这是老伴当年跑了两家店才买回来的"；修好后放门口两棵蔫青菜和一块腌肉（老城区规矩：修好了放门口自己拿走）。

### ep03 申诉老人
抱着一台蓝布裹着的旧终端（屏幕边框黄了），在铺子门口不敢进来；申诉表被格式 bug 卡了三年（"情感依据"字段）；守着老伴的声音（明知道是假的）。

### ep09 钉子户客户（老魏的客户）
中年男人，住新老城区交界；房子不大收拾得很干净；客厅桌上旧相框**照片朝下扣着**；签"保留申请"每年续签付费忍着——"留着疼，说明他还活着，在我这儿"。

### 李叔的女儿 / 儿子（ep06）
- **女儿**：中年女人，坐在屏幕前絮叨"爸你记得吃药"；一边知道是假的，一边说"爸，排骨我给你留着"——**数字守灵的情感核心**
- **儿子**：四十来岁，一直皱着眉；"妈，姐……这不行。这不是爸。"——**清醒的反对者**
