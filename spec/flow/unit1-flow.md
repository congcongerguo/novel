## 一、单集流程模板（每集按此八步走）

> 每集 = Story Circle 8 步（宪法第一条）+ 主导矛盾（A 盲区/B 惯坏/C 保留/D 制度/E 内心）+ 钩子 + 伏笔操作 + 金手指代价。以下为第一单元三集的实际落点。

### ep01《醒来在 2055》— 标杆样章（8.8）

| 环节 | 落点 |
|------|------|
| Story Circle | YOU 醒来找插座 → NEED 活下去 → GO 配给点死循环被推出 → SEARCH 旧货巷听见设备 → FIND 读懂修好 → PAY 腿蹲麻/无人应（老头"别往新城区说"）→ RETURN 换到干粮 → CHANGE "我修的不是永动机，是今天的晚饭" |

## 二、单元级流程链（跨三集的设计骨架）

| 维度 | ep01 | ep02 | ep03 |
|------|------|------|------|
| 情感曲线 | 迷茫 → 小胜 | 警惕 → 不安 | 紧张 → 被接纳 + 被盯上 |
| 冲突递进 | 生存冲突 | 关系冲突 | 制度冲突 |
| 主场 | 街头（配给点/旧货巷） | 旧货铺（入住） | 旧货铺 + 系统（跨出去） |
| 金手指 | 修设备（无人应） | 修机器换住处（风险警告） | 读系统 bug（被盯上） |
| 新设定正面撞到 | ≤3：代理制/配额制/旧设备残响 | ≤3：旧货铺/无模型/调解师 | ≤3：守灵/申诉黑箱/均衡局 |
| 钩子落点 | 设备再响（悬念） | 名片警告（危机） | 非模型提交记录（制度盯上） |

**单元节奏结论**：生存（ep01）→ 关系（ep02）→ 制度（ep03），一层比一层往外推；金手指每次解难题必配一次失败/代价（宪法第八条·3）；C 面（保留主题）在 ep03 首次正面登场，为后半程埋钩。

## 三、质量流程（已完成部分，供后续单元复用）

### Tier 1 · 单集门禁（每集定稿前，六步）
1. 三问表逐场（`scene-craft-checklist.md`）——欲望/障碍、双职责、撞到/告诉
2. 设定密度红线——正面撞到新设定 ≤ 3 样
3. 五维评分——结构/角色/节奏/文风/连续性，任一维 <7 返工
4. 去 AI 感四感——均匀/解释/安全/模板
5. 台账更新——`tracking/*.json`；伏笔连续 3 集未回收预警
6. 写单集批注 `season1/epNN.md`

> 第一单元结果：三集全过，无返工。ep01 为标杆（8.8），后续集次对齐其节奏与文风。

### Tier 2 · 幕末整体评审（每幕末，七维）
结尾/开篇同质化 · 主题句直陈密度（全季配额 ≤2）· 意象复用（呼应留、复用删）· 声线漂移 · 情感曲线节奏 · 伏笔全局回收率 · 设定密度分布

> 第一幕通读结论（`_overview.md`）：第一幕无返工级问题；"金句密度"项目级倾向已登记（ep01 格言化批注），后续集慎用同款收束。

## 五、复用规则（后续单元照此执行）

1. 每集先定：主导矛盾（A/B/C/D/E 至少一项）+ Story Circle 八步落点，再动笔
2. 表层长出一个事（A/B/D），深层同时被戳一下（C/E）——缺一不可
3. 金手指：解一题，配一败
4. 新设定每集正面撞到 ≤3，其余烂在肚子里（宪法第八条·2 冰山纪律）
5. 每集钩子类型轮换（悬念/危机/制度盯上），避免同质
6. 每完成一幕跑一次 Tier 2 七维通读，更新 `_overview.md`
7. 口头禅/记忆点靠关键时刻出现，不刷屏；每集检查声线可辨认（遮名可辨）
