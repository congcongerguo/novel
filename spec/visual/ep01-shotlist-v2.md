## 竖屏约束（v2 全局强制）

v1 的 s05 出了问题：提示词里的 `wide establishing shot` 让模型在 480×832 竖屏画布内**画了横向铺开的构图**（经检测无黑边、无旋转标记，纯构图问题）。

v2 起所有镜头强制：

1. **禁用** `wide shot / panoramic / widescreen / horizontal` 等横向构图词
2. **改用** `vertical 9:16 composition`、`vertical framing`、`tall frame`
3. 空间纵深改为**竖向堆叠**：队伍向画面深处（上方）延伸、建筑在画面上部、人物在下部
4. 负向词新增：`letterbox, black bars, widescreen crop, horizontal panorama`
5. 首帧同步：KLEIN 侧提示词加 `vertical 9:16 composition`（832×1216 原生竖屏）
