## 一致性使用规则

1. **基准 = 唯一脸**：角色后续任何变体（换场景、换表情、换机位）都从基准图做图生图派生，不重新文生图（避免脸漂移）。
2. **风格锁定**：全剧视觉统一 anime 风格（2D 动漫关键帧）——风格描述固定为：`anime style, 2D anime illustration, clean lineart, vibrant colors, cinematic anime key visual`。
3. **生成参数**：Krea2 RedMix / euler / sgm_uniform / 8 步 / cfg 1 / 1024×1024（与基准图同参数，保证兼容）。
4. **场景锚点**：分镜关键帧的取景/光线/焦段以 `spec/visual/ep01-director-cut.md` 的 AI 分镜参数附件为准。
5. **变更流程**：若某角色基准需要重选，更新本表并注明日期与旧基准去向。
