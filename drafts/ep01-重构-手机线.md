# 第一集：为什么连你自己都不想读（诊断 + 重构方案）

> 2026-09-11 · 作者反馈："感觉现在的设定即使我自己也没有太多的欲望读下去"
> 本文不改正文，只做诊断 + 提出一条重构线 + 附新开场实写，供你试读判断。

---

## 一、诊断：现在的第一集缺三样东西

### ① 主角整集没有"想要"

把他现在的全部行为列出来，你会发现它们是**横向平移**，不是"追求"：

```
没电 → 找插座（然后这事就丢了）
问路被拒 → 去配给点
配给点被拒 → 走开
路过旧货巷 → 顺手修了个东西
饿了 → 蹲下来啃干粮
```

**他一次都没有想要过什么。** 读者跟着的是"想要什么的人"——一个什么都不想要的人，读者没有理由跟着他走下去。

这是我的责任：上一轮我把"推着做的决定"（宪法 5.2）用过了头。5.2 该管的是**动作的质感**（怎么干：不立志、不仪式、顺手），我却让它把**欲望的强度**也一并抹平了。防软人那条规则（追问执着 / 行动随意）本来就是拦这个的——**但正文里只剩"随意"，"执着"没有落点**。

### ② 场景在"介绍世界"，不在"发生事情"

| 场景 | 实际功能 |
|------|---------|
| 找插座 | 展示"世界不兼容" |
| 问路 | 展示"没有模型寸步难行" |
| 配给点 | 展示"无身份=死循环" |
| 方案 B | 展示"这世界连人本身都能买" |
| 旧货巷 | 展示"判死刑的东西其实能修" |

五个场景，五个功能，功能**全是展示设定**。这是**观光式开场**——读者被带着参观世界观。

世界观是好东西，但它应该是**挡在他路上的墙**，不该是他专程去参观的展品。

### ③ 他被拒四次，但代价是零

被拒、被挤出窗口、饿肚子——可最后他蹲在巷口，笑着跟人说"你猜"。

读者不替他担心，所以**修好设备也不激动**。高级 review 那条"每集要有小赢"现在只做了一半：**赢是有了，"可能输"的压力从没建立**。小赢之所以爽，是因为之前有输的威胁。

---

## 二、改法：给他一件今天非办成的事

> **把"手机"从一句闲笔，升级成第一集的引擎。**

现在手机只出现三次：开场找插座（然后丢了）、"没人承认的两脚扁插身份证"（一个漂亮的比喻）、结束。它是**比喻**，不是**目标**。

手机应该成为他今天要办成的事。理由：

| 为什么是它 | |
|---|---|
| **具体、可拍、可解** | 不是抽象世界观的展示，是一个"弄不到电"的实际麻烦 |
| **天然私人** | 那是他在这个世界唯一的旧物——他全部的生活在里面（里面有没有某个人，留给你） |
| **和那台旧设备同类** | 都是 2026 年的东西：在这个世界没人要、没人认得、不通电 |
| **让"修设备"的动机从天上掉到地上** | 他不是热心，也不是手痒——**他是想给自己找个插座**。荒谬、自私、真实，而且完全符合"推着做"（他没立志拯救它，他只是想充电） |

## 三、逐场怎么重新咬合

| 现在 | 改后 |
|------|------|
| 开场：找插座（背景说明） | 开场：**试了七面墙**——这是他的问题，不是世界的介绍；并交代他为什么非要它亮（它跟世界不通，但我想让它亮一次） |
| 问路：泛泛问路 | 问的是**"哪儿能给这种口充电"**——他有一个明确的问题，世界一次次挡他 |
| 配给点：讨饭 | 同样在配给点，但**他要的是"能用的电"**；于是方案 B（买他的经历）变得致命——**它要买的就是手机里那"全部的经历"** |
| "你们让我卖自己？" | 改成更疼的一句（见下："你们让我把家卖了"） |
| 旧货巷：路过 → 听见响 → 顺手修 | **他看见了它的电源口**——2026 年的两脚扁插，跟他手里那个一模一样。他停下来，因为这可能是**这个世界唯一还吃他的电的东西** |
| 拨开关：手痒 | 拨开关：他本来就在找插座，拆面板是看电从哪来，**拨那一下依然是顺手**——"推着做"的质感一个字都不用改，只是底下有欲望在推它 |
| 修好后：老头给干粮 | 修好后：他问老头"这机器能给人充电吗"，然后**蹲下去，把充电头插进那个积满灰的口里** |
| 小赢：换到一顿饭 | 小赢：**他的手机亮了**（一格，百分之二）——世界不肯给他的电，一台被判死刑的旧机器给了他 |
| 集尾钩子：电流变了一下 | **保留**（现在它终于有地基了）；可叠加：手机亮起后，屏幕上出现一个不属于 2026 的东西（留白给你） |

**四个动机，一条线**：到手 → 被挡 → 绕过去 → 赢一点（但不够）。这条线一立，第一集就从"参观世界"变成"一个人想要一样东西"。

## 四、这一改，第一集同时咬住了三样东西

- **北极星**：被判报废的旧人 ⇄ 被判报废的旧物——而**牵引这两者的线，就是他手里那个充电头**（同一个 2026 年的口）
- **修物即自指**：他修它，是为了给自己充电。**自指不用额外写，它就长在骨架上**
- **追问（5.1）**：他的追问第一次有了实物落点——一个 2026 年的接口，在这个世界没人认得了，可它还在这儿，于是他想问：**为什么这东西还留着？**

## 五、新开场实写（试读用 · 约 900 字）

我到 2055 年的第一个晚上，试了七面墙。

手机没电。充电头是 2026 年的，两脚扁插。这个世界只有一个口——三个孔，圆的。插不进去。我蹲在地上，把充电头攥在手里，指腹碾过那两片磨亮的铜脚。

手机里存着我全部的生活。

说不上为什么要救它。这个世界的基站、频段、账号，全是上一世的东西；就算充满了，它也是一块废铁——一块亮着的废铁。

可我就是想让它亮一次。

一个跟这个世界不通的东西，我想让它亮一次。

天亮了，我出门。我问的不是路，是电。

"哪儿有能给这种口充电的地方？"

问了三个摊子，回答都一样："让你的模型来问。"

第四个摊主总算肯抬头。他看了看我手里那块东西，又看了看我的脸，说："去配给点。无证人员有救助配额。"

配给点的队伍排到街角。没人插队——不是守规矩，是插队那男人腕上的旗舰款，已经和闸机对谈完了。

轮到我，窗口的屏幕亮起来，一个合成的女声说："正在核验。核验失败——您不在系统内。"

"我知道。所以我来登记。"

"登记需要预约。"

"那我预约。"

"预约需要身份。"

"那我没身份。"我把充电头举到窗口前，"这东西也没身份。它需要电。"

"检测到矛盾。"合成女声平静地说，"建议方案 A：申请临时身份（审核周期四至六周）。方案 B：签署样本代理协议（即时生效，推荐，效率最优）。"

"方案 B 是什么？"

"将您的经历授权予模型公司，作为训练样本，即时获得配额。本时代约 17% 的无证人员选择方案 B。"

我站着没动。

"哪部分经历？"

"全部。"

"包括我记得的东西？"

"记忆是经历的存储形式。"

后面排队的人开始催。我低头看了一眼手里那块黑的屏幕——那里面就是"全部的经历"。

"……你们让我把家卖了。"我说。

"系统不评价方案，只提供方案。"

我被挤出窗口，站到街边。太阳很晒。

饿着肚子往回走，路过一条旧货巷。

我本来已经走过去了。

但我看见了它的电源。巷口堆着一台旧设备，半个冰箱大，锈得看不出本来颜色——侧面有个积满灰的接口。两脚扁插。

跟我手里这个一模一样。

我停下。

不是因为纸板上的字（"收旧货，拆零件，卖废铁"——字是人写的，笔画很用力，是个急脾气的人写的），也不是因为它锈得可怜。

是因为——这可能是这个世界里，唯一还吃这种电的东西。

我蹲下去。

"别碰。"有人说，"均衡局判过死刑的东西，碰了要担责。"

我没回头。我拆开面板，里面的线没乱，灰尘均匀——是自然老化的，不是暴力拆过。主板我认识，2024 年的款，前一家公司仓库里见过一堆。我顺着线路看了一遍：没烧，没爆，没一处硬伤。

只有面板上一个不起眼的电源模式拨杆，停在"待机"档。

我伸手，把它拨回"自动"。

*（下接原稿：开机 → 2026 年的界面 → "拨了个开关" → 老头给干粮 → "别往新城区说" → 啃干粮那段对话）*

**新增结尾：**

老头给了我半袋干粮和两枚硬币，声音压得更低："修得好。不过这事儿，别往新城区说。"

"这机器，"我说，"能给人充电吗？"

老头愣了一下，看了看我手里那个东西。他摇摇头，走了。

我蹲下去，把充电头插进侧面那个积满灰的口里。松的，晃了两下。

屏幕亮了。

那是我来到这个世界之后，看到的第一个 2026 年的东西——不是这台机器的界面，是我自己的。

手机屏幕亮着。一行 2026 年的字。电量：百分之二。

我盯着那百分之二，看了很久。

然后那台设备的屏幕亮了一下。

我抬起头。

*（集尾钩子·留白）*

## 六、一个字都不动的（保留清单）

这一版**不是推翻重写**，是**只改动机链**。下面这些请你放心：

- 配给点那段对话全文（"登记需要预约／预约需要身份"、"系统不评价方案，只提供方案"）——太锋利了，一个字不改
- **"拨了个开关。""……那你怎么知道拨这儿？""不知道。就是，先拨拨看。"**——全剧定调，一个字不改
- 干粮对话（"城里只有三种人吃东西……你是哪种？""你猜"）
- "我修的不是永动机，是今天这顿晚饭"
- "别往新城区说"（隐秘设定）
- 手写字的偏好（"手写的字，这个时代没人写了——但我看着顺眼"）——它和手机是同一类"旧时代的物"，正好互相印证

**改的只有一样：他的行为底下有没有一根"想要"的线。**

## 七、顺带说一个更大的问题

你说的"不想读"，可能不只指第一集——**设定也已经是"读不动"的量了**：

```
constitution.md / novel-bible.md / settings/worldview.md
settings/world-foundation.md / settings/world-texture.md
brief.md / spec/characters/ 6 份档案 / spec/tracking/ 3 份台账
spec/review/ 4 份评审 / spec/scene-craft-checklist.md …
```

这套东西**为"正确"服务得很好，为"想写"服务得很差**。下次写正文时你不可能全读；读的时候满眼是红线、保险、铁律——创作欲就是被这些压掉的。

建议：**做一张"一页纸"**（写正文时只看它）：一句话故事 / 根冲突一句话 / 主角三个动作质感（追问执着·行动随意·修物即自指）/ 每集种子一行 / 三条红线。其余全部退成"查得到但不用读"的后台。

要不要做，你说。
