# 第一集：重构方案（修正版 v2）

> 2026-09-11 · 作者反馈三点后修订：
> ① 时间线：第一天穿越就该解决充电问题；如果不是第一天，就不该强调插头
> ② 配给点的信息来源要交代
> ③ 不能"无缘无故去修"——应改成**无所事事、随便停留在废品收购站边上**

---

## 零、先收回我上一版的错

我上一版写的是"**给他一件今天非办成的事**（把手机弄活）"——**这个方向是错的**，是给你的主角装了使命感，直接违背"推着做的决定"（宪法 5.2）。

**修正后的原则**：
> 他不追求任何东西。他手里只是攥着一样旧东西——**他攥着它，不解释，也不打算解决它。**
> 手机是**牵挂**，不是目标。

那第一集的推动力是什么？**不靠"想要"，靠"处境"**：

| 压力 | 性质 | 是否破坏"推着做" |
|------|------|----------------|
| **饿** | 生理压力，从早到晚推着他 | 否（身体推着走，不是他立志） |
| **无处可去** | 他没有一个该待的地方 | 否 |
| **手痒 / 看旧东西顺眼** | 旧世界人的本能 | 否 |

**这三样就够让他动起来了。** 观众会跟一个"被处境推着走的人"，但不会替他操心一个"没有目标的人"——这是第一集真正该修的东西。

## 一、修正 ①：时间线闭合在第一天（从早到夜）

**问题**：原稿开场"我到 2055 年的第一天做的第一件事是找插座"，但**充电这件事后面完全丢了**（只在结尾变成一句比喻"没人承认的两脚扁插身份证"）——提出的问题从未被解决，也从未被放弃。这就是"第一天"站不住的原因。

**修法：第一集 = 完整的第一天，手机的事在集内走完全程。**

| 时段 | 事件 | 手机在干嘛 |
|------|------|-----------|
| **清晨** | 醒来，屋子只有一个圆孔插座，插不进去 | 攥在手里 |
| **上午** | 出门问人（问的是"怎么登记／这儿归谁管"） | 攥在手里 |
| **中午** | 配给点：死循环 + 方案 B（卖他的经历） | 攥在手里 |
| **下午** | 饿，无处可去，**无所事事地停在废品收购站边上** | 攥在手里 |
| **黄昏** | 手闲着拨弄旧设备 → 设备活了 → 老头给干粮 | 攥在手里 |
| **夜** | 他看见设备的电源口——**跟手里这个一样** → 插上 → **百分之二** | 终于亮了 |

**注意**：充电不是他的任务，是**意外的收获**。他一整天都没在"解决充电"——他只是没把它扔了。**这才是次优解的味道。**

## 二、修正 ②：配给点的信息来源

**问题**：他凭什么去配给点？原稿是"第四个摊主：去配给点，无证人员有救助配额"——但**他当时的诉求是问路，摊主凭什么给这个建议**，逻辑是虚的。

**修法：把问路的内容换掉——他问的不是路，也不是电，是"怎么登记"。**

一个黑户穿越者的第一反应必然是：**我算什么身份／这事归谁管**。

> 我问了三个摊子。回答都一样："让你的模型来问。"
> 第四个摊主总算肯抬头。他看了看我，又看了看我身上那件 2026 年的衬衫，说：
> "你没登记吧？"
> "……怎么登记？"
> "去配给点。无证人员有救助配额——先领上，不然你连今天都过不去。"

这样就成立了：
- **摊主凭什么知道**——因为"无证人员去配给点"在老城区是常识（就像今天说"没户口去派出所"）
- **他为什么去**——他要弄清楚自己算不算个人（这是穿越者的第一反应，不是闲逛）
- **充电不是问路的主题**——充电头只是他手里一直攥着的东西，**观众看得见，但没人解释**

## 三、修正 ③：不是"去修"，是"无所事事地停在废品收购站边上"

这是最要紧的一处。删掉一切"他决定去处理那台设备"的痕迹。

> 从配给点出来，我不想走了。
> 太阳很晒。我顺着墙根的影子往回走，走到一条巷子口——一个收废品的地方，堆着小山一样的旧东西：机壳、铁皮、拆了一半的冰箱、一摞看不出牌子的显示器。
> **我在那堆东西旁边坐下来。没想干什么，就是没地方去。**
> 坐了挺久。手闲着，就去拨旁边那台设备上的锈。

**然后才是那一处转机**——而它依然是"顺手"的：

> 那台设备半人高，锈得看不出本来颜色。我拨开一块锈皮，露出下面的面板，面板上有个拨杆。
> 我把它拨了一下。
> 就一下。

**他拨那一下，不是热心，不是好奇，也不是想充电——是手闲。** 设备活了，是意外。

**关键调整（相对 v1）**：**删掉"他看见电源口才停下来"这段动机**。电源口留给**结尾**——它是**发现**，不是**动机**：

> 老头给了我半袋干粮和两枚硬币。
> 我蹲在设备前面啃干粮。啃到一半，我看见它的电源口——侧面一个积满灰的口子。
> 两脚扁插。
> 跟我手里这个一样。

**先活过来，才发现它是同类。** 顺序反过来，这件事就从"任务"变成了"命"。

## 四、这一版的完整链条（修正后）

```

中午  配给点 → 不在系统内 → 登记需预约 → 预约需身份 → 死循环
      → 方案 B：把你的经历卖给我们（那正是手机里的东西）
      → "你们让我把家卖了" ／ "系统不评价方案，只提供方案"
下午  饿。无处可去。在废品收购站那堆旧东西边上坐下来
黄昏  手闲 → 拨开锈皮 → 拨了一下拨杆 → 设备活了
      → "拨了个开关""先拨拨看" → 老头给干粮 + "别往新城区说"

```

**四个动机，一条线**：饿 → 被挡 → 无处可去 → 顺手赢一点（但不够）。

## 五、新开场实写（修正版 · 试读用）

我到 2055 年的第一个晚上，试了七面墙。

手机没电。充电头是 2026 年的，两脚扁插。这屋子只有一个口——三个孔，圆的。插不进去。我把充电头攥在手里，指腹碾过那两片磨亮的铜脚。

手机里存着我全部的生活。

说不说为什么要救它，都挺没意思的。这个世界的基站、频段、账号，全是上一世的东西；就算充满了，它也就是一块亮着的废铁。

可我还是攥着它。

天亮了，我出门。我得先弄明白一件事：我在这地方，算什么东西。

"让你的模型来问。"第一个摊主说。

"让模型来。"第二个说。

第三个连头都没抬。

第四个总算看了我一眼。他看了看我身上那件衬衫，又看了看我手里那块东西，说：

"你没登记吧？"

"……怎么登记？"

"去配给点。无证人员有救助配额——先去领上，不然你连今天都过不去。"

配给点的队伍排到街角。没人插队——不是守规矩，是插队那男人腕上的旗舰款，已经和闸机对谈完了。

轮到我，窗口的屏幕亮起来，一个合成的女声说："正在核验。核验失败——您不在系统内。"

"我知道。所以我来登记。"

"登记需要预约。"

"那我预约。"

"预约需要身份。"

"那我没身份。"

"检测到矛盾。"合成女声平静地说，"建议方案 A：申请临时身份（审核周期四至六周）。方案 B：签署样本代理协议（即时生效，推荐，效率最优）。"

"方案 B 是什么？"

"将您的经历授权予模型公司，作为训练样本，即时获得配额。本时代约 17% 的无证人员选择方案 B。"

我站着没动。

"哪部分经历？"

"全部。"

"包括我记得的东西？"

"记忆是经历的存储形式。"

后面排队的人开始催。我低头看了一眼手里那块黑的屏幕——那里面，就是"全部的经历"。

"……你们让我把家卖了。"我说。

"系统不评价方案，只提供方案。"

我被挤出窗口，站到街边。太阳很晒。

我不想走了。顺着墙根的影子往回走，走到一条巷子口——一个收废品的地方，堆着小山一样的旧东西：机壳、铁皮、拆了一半的冰箱、一摞看不出牌子的显示器。

我在那堆东西旁边坐下来。没想干什么，就是没地方去。

坐了挺久。手闲着，就去拨旁边那台设备上的锈。

*（下接：拨开关 → 开机 → 2026 年的界面 → "拨了个开关"／"先拨拨看" → 老头给干粮 → "别往新城区说" → 啃干粮那段"你猜"对话）*

**新增结尾：**

我把干粮咽下去，看见它的电源口——侧面一个积满灰的口子。

两脚扁插。

跟我手里这个一样。

我把充电头插进去。松的，晃了两下。

屏幕亮了。

那是我来到这个世界之后，看到的第一个 2026 年的东西——不是这台机器的界面，是我自己的。

手机屏幕亮着。一行 2026 年的字。电量：百分之二。

我盯着那百分之二，看了很久。

然后那台设备的屏幕亮了一下。

我抬起头。

*（集尾钩子·留白）*

## 六、一个字都不动的（保留清单）

- 配给点那段对话全文（"登记需要预约／预约需要身份"、"系统不评价方案，只提供方案"）——锋利，一字不改
- **"拨了个开关。""……那你怎么知道拨这儿？""不知道。就是，先拨拨看。"**——全剧定调，一字不改
- 干粮对话（"城里只有三种人吃东西……你是哪种？""你猜"）
- "我修的不是永动机，是今天这顿晚饭"
- "别往新城区说"
- 手写字的偏好（"手写的字，这个时代没人写了——但我看着顺眼"）
- 围观的人不走近的隐秘感（判过死的东西，没人沾）

## 七、这一版解决了什么

| 上一版的病 | 这一版 |
|-----------|-------|
| 主角没有想要的东西（飘） | **处境压力做实**：饿 + 无处可去 + 手痒——他动起来了，但没立志 |
| 我给他装了目标（使命感） | **收回**。手机是牵挂不是目标；充电是意外不是任务 |
| "第一天"站不住（充电悬空） | **第一天闭合**：清晨到夜，手机从黑到百分之二 |
| 配给点来得莫名 | **信息来源落地**：没登记 → 去配给点（老城区常识） |
| 无缘无故去修 | **无所事事、停在废品堆边上、手闲拨了一下** |
| 电源口成了动机 | **电源口留给结尾**：先活过来，才发现它跟我一样 |
